### 一万部虚构影片查询基准

命令：`python tests/benchmark_catalog.py 10000`。同一台机器、同一份 SQLite 数据，旧路径加载并序列化全库，新路径查询并序列化 60 部摘要；每部含简介和 20 张剧照引用。

| 项目 | 本次结果 |
| --- | ---: |
| 旧全库详情响应 | 61,039,691 字节 |
| 新首页摘要响应 | 19,461 字节 |
| 新单页查询及 JSON 序列化中位耗时（5 次） | 20.8 ms |
| 旧全库读取及 JSON 序列化耗时 | 1,559.39 ms |
| 厂商与标签组合筛选（100 部匹配） | 45.26 ms |

以上是合成数据的本机基准，不包含网络、磁盘扫描、图片处理和浏览器渲染，不代表飞牛实机打开页面的耗时。
